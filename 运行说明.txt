二、运行方法（推荐 Python 3.13，验证环境 Python 3.13.16）
先完整解压，再进入“Lasso作业_代码与数据”文件夹；不要在压缩包内运行。

Windows：
1. 打开终端，进入解压后的文件夹。
2. py -3.13 -m venv .venv
3. .venv\Scripts\python.exe -m pip install -r requirements.txt
4. .venv\Scripts\python.exe -m jupyterlab

macOS / Linux：
1. 打开终端，进入解压后的文件夹。
2. python3.13 -m venv .venv
3. .venv/bin/python -m pip install -r requirements.txt
4. .venv/bin/python -m jupyterlab

打开“4.1机器学习与因子筛选_整合.ipynb”，选择新建环境的 Python 内核，重启内核并依次运行所有单元。
若已有其他 Python 环境，不要只凭 Notebook 保存的“ml-course”名称选内核，应选择安装了 requirements 的解释器。
出现数据库或模块找不到时，检查是否完整解压，以及工作目录是否为 Notebook 所在文件夹。
首次安装依赖需要联网；依赖安装后正常运行不需要联网。

三、方法及结果口径
仅修改 Lasso 方法和直接对应说明；原有特征构造、其他模型与分析正文保留。
数据仍含 153 列；Lasso 根据变量定义排除年份、重复无风险收益、q 市场项及相应交互项，有效候选 111 个。
市场变量统一采用 FF 市场超额收益；macro_dy 在本数据中实际为股息增长率，不是通常的股息收益率。
每个行业按时间取前 80% 训练、后 20% 历史测试。
训练期做 5 个外层扩展窗口验证，每折独立完成内层 3 折选 alpha、100 次 12 个月分块重采样、稳定筛选和重拟合。
入选频率至少 70%、非零系数方向一致率至少 90%，最多保留 5 个变量；允许空模型。
最终在完整训练期重复同一流程，固定随机种子 42；种子 2026 只用于复现性复核，不择优替换模型。
求解沿用粗细搜索、热启动、固定容差及收敛重试；重采样或最终重拟合仍失败时停止并报错。

lasso_stability_results/：
- 优化汇总.csv：阈值、入选数、跨折及种子 Jaccard、外层验证误差、耗时。
- 因子稳定性.csv：完整训练期各变量的频率、方向一致率及筛除原因。
- 各阶段稳定性.csv：外层折、完整训练期、种子复核的详细记录。
- 分折验证记录.csv：训练/验证日期、入选变量及外层验证误差。
- 参数搜索记录.csv、调参求解日志.csv、重采样求解日志.csv：调参与实际收敛过程。
- 行业表现.csv、最终入选因子.csv：最终表现和非零系数。

四、解释时注意
频率是在所选 alpha 固定条件下的经验诊断，不是显著性或“真实因子概率”，也没有理论错误发现控制保证。
两个空集合的 Jaccard 按 1 处理，应同时查看空模型折数，不能把空模型一致当成稳定因子证据。
目标是稳定性与解释性，测试误差未必改善；原历史测试集已在此前方法对照中查看，本次属于探索性评估。
使用同月变量解释同月收益，不是可以实时实施的下一期预测；宏观数据也未做发布日期与历史版本回溯。
公开数据存在历史修订；数据库来源、单位和兼容处理见 data_sources/数据来源与兼容说明.txt。
原 Notebook 后文分析文字按要求未改，其中旧数值应与本次输出核对，不能直接当成本版结论。
本机虚拟环境、IDE 设置不随包发送；同学按上述步骤创建自己的环境。
